# Story Space — GitHub Pages

1. Extract this ZIP.
2. Add its contents to the root of the target GitHub repository. index.html must be at the root, not inside another folder.
3. In repository Settings > Pages, choose Deploy from a branch, then main and / (root), and Save.
4. Wait for the deployment to complete. GitHub Pages will show the live URL.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

No build step, API keys, or ChatGPT hosting are needed. All Three.js dependencies are included locally. Keep all JS files together.

Edit stories.js for story content, style.css for appearance, and app.js for navigation. Optional image paths are supported on story entries. The content is fictional sample content; this is an approximation inspired by the supplied recording, not an exact SBS copy. Browser interaction QA has not been performed.
